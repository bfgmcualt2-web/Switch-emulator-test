Play the included demo

Move with WASD/arrow keys or the on-screen controls. Jump with Space/A. Collect sparks while avoiding the red drones. Bluetooth controllers that expose the Gamepad API also work.

What this can and cannot do

  • Runs entirely as static files; no server-side CPU/GPU resources are used.
  • Includes a Horizon-style system scaffold for power state, HID, CPU/GPU/audio service boundaries, and sandboxed file staging.
  • Stores only metadata about loaded files, never uploads ROMs or keys.
  • A production Nintendo Switch emulator requires a substantial CPU/GPU/audio/kernel WebAssembly core plus legally supplied firmware, keys, and game images.
  • This app does not decrypt commercial games, provide keys, or bypass copy protection; it only exposes a legal homebrew WebAssembly core plug-in boundary.
